# SR-004: Build Thin Vecs Client Connection Loop

## Objective

Replace the Colyseus `ecsMirror` client with `ClientWorld.connectDgram` and a thin client loop.

## Scope

- Create a client networking module that connects to the vecs server.
- Instantiate `ClientWorld` with `NETWORK_COMPONENTS` and a local entity ID range.
- Install vecs client apply/send systems.
- Capture keyboard input and send intent through `client.setInput(...)`.
- Handle disconnect by clearing mirrored entities and reconnecting.
- Keep rendering systems local.

## Input Contract

```ts
  rotateRight: boolean,
  shoot: boolean
}
```

## Implementation Notes

- The client must not call `initGame()` after this migration path is active.
- The client should not create gameplay entities except local resources and cosmetic particles.
- Keep DOM setup in the client.
- Do not send key codes to the server; send semantic intent.

## Acceptance Criteria

- Client connects to server using vecs-client.
- Client sends input every frame while connected.
- Client receives and stores mirrored entities from the server.
- Client recovers from disconnect by clearing mirrored state and reconnecting.
