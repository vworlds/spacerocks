# SR-012: Implement Networked Effect Markers and Local Particles

## Objective

Replace authoritative client-side particle spawning with server-created effect marker entities and client-local rendering effects.

## Scope

- Add `ExplosionView` or equivalent network component.
- Add server-local `Ttl` component for short-lived effect entities.
- Create explosion marker entities from server collision/death events.
- Render explosions on clients when markers appear.
- Optionally spawn local-only particles in the client from marker metadata.

## Dependencies

- `SR-010`
- `SR-011`

## Blocks

- `SR-014`

## Implementation Notes

- Do not sync individual particles.
- Explosion marker should contain enough deterministic data for all clients to see similar effects: position, color, size/count hint, seed, duration.
- Marker entities can be `Networked` and destroyed automatically when TTL expires.
- If particles are local entities, keep their entity IDs in the client-local range.

## Acceptance Criteria

- Asteroid, alien, player, projectile, and pickup effects are visible in clients.
- Effect marker entities disappear quickly.
- Network traffic does not include individual particle entities.
- Client particles do not affect gameplay.
