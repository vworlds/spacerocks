# SR-014: Remove Old Colyseus, Custom Networking, and Client Authority

## Objective

Cleanly remove obsolete networking and client-side authoritative gameplay once the vecs migration is functional and tested.

## Scope

- Delete Colyseus `UniverseRoom` and tests.
- Delete `apps/client/src/network/ecsMirror.ts`.
- Delete custom `packages/common/src/network/protocol.ts` and old snapshot/delta helpers.
- Remove Colyseus dependencies from package files and lockfile.
- Remove browser-side calls to `initGame()` and gameplay system imports.
- Remove or relocate client-side factories and systems that are now server-owned.
- Update README or developer docs with new server/client startup flow.

## Dependencies

- `SR-003`
- `SR-004`
- `SR-010`
- `SR-011`
- `SR-013`

## Blocks

- Final release of the migration.

## Implementation Notes

- Do this late. Premature deletion makes parallel migration harder.
- Keep client render systems and client-only particles.
- Verify no import path still references Colyseus or custom network protocol.
- Verify package lock no longer contains Colyseus packages.

## Acceptance Criteria

- No `colyseus` or `colyseus.js` dependency remains.
- No Colyseus imports remain.
- No custom ECS snapshot/delta protocol remains.
- Client does not instantiate authoritative gameplay entities.
- Server is the only authority for gameplay state.
- Tests, typecheck, lint, and manual multiplayer smoke test pass.
