# SR-008: Move Spawning, Waves, Pickups, Aliens, and RNG to Server

## Objective

Move all authoritative spawning and timed game progression to the server.

## Scope

- Migrate asteroid spawning and splitting support.
- Migrate wave progression.
- Migrate alien spawning.
- Migrate pickup spawning and pickup metadata.
- Replace `RandomClock.effectFunc` with server-owned timed spawn systems.
- Replace gameplay `Math.random()` usage with server-side RNG utilities.

## Dependencies

- `SR-003`
- `SR-005`

## Blocks

- `SR-010`

## Systems and Factories to Move

- `game.ts` initialization logic, server equivalent only.
- `Wave`
- `RandomClockSystem`
- `createAsteroid`
- `createAlien`
- `createPickup`

## Implementation Notes

- Spawns use fixed world dimensions, not browser canvas dimensions.
- Random asteroid shapes are server-generated and synced through `Shape` or a compact `AsteroidView` representation.
- Pickup effects are enum-driven and resolved on server collision.
- Spawn timers should pause or no-op when the game state is not playing.

## Acceptance Criteria

- Server initializes the game world.
- Server progresses waves when asteroids/aliens are cleared.
- Server spawns pickups and aliens over time.
- Clients render spawned entities without local spawn code.
