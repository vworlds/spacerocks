# SR-001: Replace Dependencies and Build Foundation

## Objective

Prepare the repository for vecs-client/vecs-server and remove the Colyseus foundation without yet deleting the old gameplay implementation.

## Scope

- Add `@vworlds/vecs-client`, `@vworlds/vecs-server`, and `@vworlds/vecs-wire` dependencies.
- Add server HTTP dependency required by `VecsListener`, expected to be `express` plus types if needed.
- Remove `colyseus` and `colyseus.js` after replacement bootstraps compile.
- Enable TypeScript support needed by `vecs-wire` decorators.
- Keep package versions aligned with the root `@vworlds/vecs` override strategy.
- Ensure Vite/server builds can resolve the new packages.

## Dependencies

- None.

## Blocks

- `SR-003`
- `SR-004`

## Implementation Notes

- The local vecs demo uses `experimentalDecorators` in TypeScript.
- Spacerocks currently uses `moduleResolution: bundler`; verify this works with published vecs packages before changing module settings.
- Avoid deleting Colyseus code in this ticket unless the replacement shell is already compiling.

## Acceptance Criteria

- `npm install` updates the lockfile with vecs-client/server/wire packages.
- `npm run typecheck` reaches current application code without dependency resolution failures.
- The repo can import `ClientWorld`, `ServerWorld`, `VecsListener`, `Networked`, `NetworkInput`, `NetworkClient`, `View`, and `type as wireType`.
- No gameplay behavior changes are required in this ticket.
